Способы оплаты

Добавьте до 4 карт для приёма оплаты от клиентов. Способ оплаты «На карту» — единственный доступный покупателям вариант оплаты.

Оплата заказа

Переведите сумму заказа на карту продавца, затем нажмите «Я оплатил» и отправьте чек в чат.

Telegram-бот

Заказы будут приходить в этот бот. Создайте бота через @BotFather и укажите токен и Chat ID.

Это сообщение автоматически придёт покупателю сразу после того, как он напишет вам в первый раз по товару.

Бот для публикации товаров

Отдельный бот — для заказов используйте другой, указанный выше. Этого бота нужно добавить администратором в канал с правом «Публикация сообщений», иначе публикация в канал работать не будет.

Заполните хотя бы одно из полей выше (канал и/или чат бота). Каждый новый товар автоматически публикуется туда с фото, названием, артикулом, ценой и ссылкой на товар. Уже добавленные товары можно опубликовать вручную: Админка → Товары → «Публикация товаров».

Бот сайта (подтверждение регистрации и уведомления)

Один бот для двух задач: подтверждение номера при регистрации и подписка клиента на уведомления о новых товарах и акциях. Создайте бота через @BotFather, укажите токен и его юзернейм (без @, например HorizonVerifyBot). Если не заполнено — регистрация проходит без подтверждения, а окно с уведомлениями не показывается.

Эту ссылку с кнопкой «Подписаться» бот присылает клиенту сразу после включения уведомлений.

Курьеры

Реквизиты, на которые курьеры еженедельно переводят налог, и процент от суммы, заработанной курьером за неделю.

Этот адрес видит клиент при выборе «Самовывоз» и курьер — как место, откуда забирать товар для доставки.

ИИ — автозаполнение товара

Провайдер для кнопки «ИИ» в форме добавления товара — она сама подбирает описание и характеристики по названию. Если один провайдер не работает в вашем регионе, переключитесь на другой.

Публикация товаров

Отметьте товары и нажмите «Опубликовать» — карточки с фото, названием, артикулом, ценой и ссылкой на товар уйдут в канал и/или бот, настроенные в Профиль → Telegram-бот → «Бот для публикации товаров».

Новый товар

Впишите название товара и нажмите «ИИ» — автоматически подберутся описание и характеристики (каталог, цену, артикул, бренд и фото укажите вручную).

Если указано количество — при заказах оно будет автоматически уменьшаться, а при достижении нуля товар сам станет «нет в наличии». Галочка выше используется только если количество не указано.

Для телефонов укажите варианты вроде «256ГБ», «512ГБ» и, если нужно, свою цену для каждого — при выборе варианта цена в карточке товара изменится автоматически. Если цену не указывать, будет использована обычная цена товара.

Несколько вариантов сразу можно ввести через запятую (тогда указанная цена, если есть, применится ко всем). Нажмите на добавленный вариант, чтобы изменить его цену.

Нажмите на цвет, чтобы отметить его — он появится в карточке товара.
